# AURA • Personnel Welfare Intelligence (SIH26186)
Ministry of Home Affairs • Smart India Hackathon 2026

## Project Structure
- `landing.html` - Main platform overview and warm human-centric introduction.
- `pages/welfare-dashboard.html` - Welfare Officer command center for monitoring and action.
- `pages/commander-dashboard.html` - Aggregated, privacy-first unit resilience view.
- `pages/personnel-dashboard.html` - Individual secure portal for personnel.
- `pages/personnel-detail.html` - Explainable AI risk factors and intervention triggers.
- `css/` - Modular design system styles.
- `js/` - Shared state and UI controllers.

## Running Locally
Simply open `landing.html` in any modern web browser or serve via Live Server in VS Code.
